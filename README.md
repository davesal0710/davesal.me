# David Salazar's portfolio

This repository contains the static source for [davesal.me](https://davesal.me). `index.html`, `styles.css`, `script.js`, and `assets/` are the deployable site files.

To preview locally, run `python3 -m http.server 8000` from this directory and open `http://localhost:8000`.

The current ChatGPT Sites project is managed separately. Updates to this GitHub repository do not automatically update that deployment. Copy the corresponding files into its `dist/` directory and deploy through Sites when you want both versions to match.
